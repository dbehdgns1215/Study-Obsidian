
# Virtual Memory
- 쉽게 말해 하드디스크 같은 2차 메모리를 RAM과 같은 주기억장치 메모리와 함께 일종의 추상화한 것
- 심지어 Virtual Memory는 모두(프로세스)에게 많이 줄 수가 없다.
- 한 프로세스당 1GB씩 준다고 생각하면, 40개만 띄워도 40GB이다.
- 근데 실제로는 4GB씩 준다고 해도 1.7GB밖에 못쓰기도 한다.
- 각 프로세스마다 독립적인 공간을 가지고 있으며, 여러 프로그램들이 동시에 작동될 수 있도록 지원해주는 OS를 멀티 태스킹 운영체제라고 한다.
	- 멀티 태스킹 환경에서는 각각의 프로세스가 가상 메모리라는 체계를 활용하고 있다.
