- 네트워크 설정 부분
	- `보안 그룹`이란 AWS 클라우드에서의 네트워크 보안을 의미함.
	- EC2 인스턴스를 `집`으로 생각한다면, 보안 그룹은 `집 바깥쪽`에 쳐져있는 울타리와 대문이고 생각하면 된다.
	- 집 바깥쪽에서 집으로 접근해도 되는지 안되는지 검사해주는 것과 동일.
