
# 람다의 기본 형태

```java
(매개변수들) -> { 실행문 }
```

### 매개변수가 1개일 때 (소괄호 생략 가능)

```java
x -> System.out.println(x);
```

```java
(String x) -> System.out.println(x);
```

```java
x -> { System.out.println(x); }
```


## 매개변수가 2개 이상일 때 (소괄호 필수)

```java
(x, y) -> x + y
```

```java
(int x, int y) -> { return x + y; }
```

- 타입은 **컴파일러가 추론**함.
```java
(int x, int y) -> x + y   // 가능
(x, y) -> x + y           // 더 흔함
(int x, y) -> x + y       // 컴파일 에러
```

# 한 줄이면 `{}` + `return` 생략 가능

```java
() -> System.out.println("작업 중");
```

```java
(x, y) -> x + y;
```

- 여러 줄이면 `{}` 필수 + `return` 필요
```java
(x, y) -> {
    int sum = x + y;
    return sum;
}
```
