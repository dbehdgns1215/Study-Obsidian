
# 람다의 기본 형태

```java
(매개변수들) -> { 실행문 }
```

### 매개변수가 1개일 때 (소괄호 생략 가능)

```java
x -> System.out.println(x);
```

```java
(String x) -> System.out.println(x);
```

```java
x -> { System.out.println(x); }
```


## 매개변수가 2개 이상일 때 (소괄호 필수)

```java
(x, y) -> x + y
```

```java
(int x, int y) -> { return x + y; }
```

- 타입은 **컴파일러가 추론**함.
```java
(int x, int y) -> x + y   // 가능
(x, y) -> x + y           // 더 흔함
(int x, y) -> x + y       // 컴파일 에러
```

# 한 줄이면 `{}` + `return` 생략 가능

```java
() -> System.out.println("작업 중");
```

```java
(x, y) -> x + y;
```

- 여러 줄이면 `{}` 필수 + `return` 필요
```java
(x, y) -> {
    int sum = x + y;
    return sum;
}
```

# 람다는 **return 타입을 쓰지 않는다**

```java
interface Calc {
    int add(int a, int b);
}
```

```java
Calc c = (a, b) -> a + b;
```


# 람다를 쓸 수 있는 조건

```java
@FunctionalInterface
interface Runnable {
    void run();
}
```

```java
@FunctionalInterface
interface Consumer<T> {
    void accept(T t);
}
```

- 메서드가 2개 이상이면 람다 사용 불가능.

# 자주 사용하는 표준 함수형 인터페이스
|인터페이스|시그니처|의미|
|---|---|---|
|`Runnable`|`() -> void`|실행|
|`Consumer<T>`|`(T) -> void`|소비|
|`Supplier<T>`|`() -> T`|공급|
|`Function<T,R>`|`(T) -> R`|변환|
|`Predicate<T>`|`(T) -> boolean`|조건|


## this 차이 (익명 클래스 vs 람다)

```java
`this`
```
- 익명 클래스 → **자기 자신**
- 람다 → **바깥 클래스**


>람다는  
>“딱 하나의 추상 메서드”만 있을 때만 가능
>또한 “함수형 인터페이스의 단일 메서드를 간결하게 구현하는 문법”이다.
