
# 문법

```java
인터페이스명 또는 부모클래스명 객체 = new 인터페이스명 또는 부모클래스명() {
    // 메서드 구현
};
```

# 예시

```java
Runnable r = new Runnable() {
    @Override
    public void run() {
        System.out.println("익명 클래스 실행");
    }
};

r.run();
```


```java
abstract class Animal {
    abstract void sound();
}

Animal dog = new Animal() {
    @Override
    void sound() {
        System.out.println("멍멍");
    }
};

dog.sound();
```

```java
Thread t = new Thread(new Runnable() {
	public void run() {
		System.out.println("작업 중");
	} 
});
```
- `Runnable` 익명 클래스를 만들어서 `Thread` 클래스에게 인자로 넘겨주는 상황임.
