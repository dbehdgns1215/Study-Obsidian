
# 메모리와 포인터

메모리 주소
0x0000              메모리 셀 1 Byte
0x0001              메모리 셀 1 Byte
0x0002              메모리 셀 1 Byte
0x0003              메모리 셀 1 Byte
0x0004              메모리 셀 1 Byte

- int 변수를 저장한다 -> 4 Byte 할당

메모리 주소
0x0000              int i
0x0001              int i
0x0002              int i
0x0003              int i
0x0004              메모리 셀 1 Byte

- int i의 주소 -> 사용하는 영역의 첫 번째 주소 -> 0x0000
