## 2️⃣ SELECT 문법

**형식**

```sql
SELECT [DISTINCT] 컬럼1, 컬럼2, ... [AS 별명] [*]   -- (6)
FROM 테이블명                                       -- (1)
[WHERE 조건절]                                      -- (2)
[GROUP BY 컬럼명]                                   -- (3)
[HAVING 조건절]                                     -- (4)
[ORDER BY 컬럼명 ASC|DESC]                          -- (5)
```

### 🔹 조건

- `DISTINCT`: 중복 제거
    
- `*`: 모든 컬럼 선택
    
- 조건절 연산자: `AND`, `OR`, `LIKE`, `IN`, `BETWEEN AND`, `IS NULL`, `IS NOT NULL`
    

### 🔹 연산자

|연산자|의미|
|---|---|
|`=`|같다|
|`!=`, `^=`, `<>`|같지 않다|
|`>=`, `<=`, `>`, `<`|비교 연산자|
|`AND`, `OR`|논리 연산자|
|`BETWEEN AND`, `IN`, `LIKE`|범위 / 패턴 조건|
|`IS NULL`, `IS NOT NULL`|NULL 여부 판단|

### 🔹 정렬

```sql
ORDER BY 컬럼명 [ASC|DESC]
```

- `ASC`: 오름차순 (기본값)
    
- `DESC`: 내림차순
    
- 컬럼명 대신 숫자도 사용 가능
    

### 🔹 그룹과 조건

- `GROUP BY`: 그룹 함수(`MAX`, `MIN`, `SUM`, `AVG`, `COUNT` 등)와 함께 사용
    
- `HAVING`: 그룹핑된 결과에 대한 조건절

## 5️⃣ View (뷰)

**개념:**  
복잡한 쿼리를 쉽게 관리하기 위해 **저장된 쿼리(Stored Query)** 형태로 만들어 사용하는 객체.

**사용 이유:**

- 복잡한 SQL을 단순화
    
- 자주 쓰는 조회문을 재사용 가능
    
- 특정 데이터만 보여주는 보안적 측면 강화

# 🧩 JSP & Servlet

---

## 1️⃣ JSP 기본 문법 (스크립트 요소 4가지)

| 구분        | 태그              | 설명                       |
| --------- | --------------- | ------------------------ |
| **선언문**   | `<%! ... %>`    | 변수 및 메소드 선언              |
| **스크립트릿** | `<% ... %>`     | 코드 작성 (if, for, while 등) |
| **표현식**   | `<%= ... %>`    | 변수 또는 메소드 결과 출력          |
| **주석**    | `<%-- ... --%>` | JSP 주석                   |

---

## 2️⃣ EL (Expression Language)에서 쿠키 / 세션 접근

| 구분  | 예시                      | 설명             |
| --- | ----------------------- | -------------- |
| 쿠키  | `${cookie.쿠키명.value}`   | 쿠키 값 가져오기      |
| 세션  | `${sessionScope.세션속성명}` | 세션에 저장된 값 가져오기 |

---

## 3️⃣ Servlet의 Filter & Listener

|구분|설명|실행 시점|
|---|---|---|
|**Filter**|요청/응답을 가로채서 전처리/후처리|서블릿 실행 전/후|
|**Listener**|특정 이벤트(세션 생성, 요청 시작 등)를 감지|웹 애플리케이션 동작 중 자동 실행|

---

## 4️⃣ 서블릿 주요 객체

|객체명|설명|
|---|---|
|`HttpServletRequest`|클라이언트의 요청 정보를 담음 (파라미터, 헤더, 쿠키 등)|
|`HttpServletResponse`|클라이언트에 응답 보낼 때 사용 (응답 헤더, 리다이렉트 등)|
|`HttpSession`|사용자별 세션 정보 저장 (로그인 정보, 장바구니 등)|

---

## 5️⃣ JSP 내장 객체

|객체명|설명|
|---|---|
|`request`|요청 정보 (파라미터, 헤더 등)|
|`response`|응답 처리 (리다이렉트, 콘텐츠 타입 등)|
|`out`|브라우저로 출력 스트림|
|`session`|사용자별 서버 저장 공간|
|`exception`|에러 페이지에서 예외 처리|

## 7️⃣ JDBC 주요 객체

```java
Connection conn = DBUtil.getInstance().getConnection();
PreparedStatement pstmt = conn.prepareStatement(sql);
ResultSet rs = pstmt.executeQuery();
```

- `Connection`: DB 연결
    
- `PreparedStatement`: SQL 미리 컴파일 후 실행 준비
    
- `ResultSet`: SELECT 결과 저장

## 🔟 JSP MVC 패턴 동작 흐름

1. 클라이언트가 요청을 전송
    
2. **컨트롤러**가 요청을 받음
    
3. 컨트롤러는 **모델**에 처리 요청
    
4. 모델은 처리 후 결과를 컨트롤러에 반환
    
5. 컨트롤러는 **뷰(JSP)** 에 결과 전달
    
6. 뷰가 결과를 사용자에게 응답

## 12️⃣ 서블릿의 생명주기

| 메서드         | 실행 시점                 | 설명           |
| ----------- | --------------------- | ------------ |
| `init()`    | 서블릿이 처음 생성될 때 (1회 실행) | 초기 설정 작업     |
| `service()` | 요청이 들어올 때마다 실행        | 요청 처리 로직     |
| `destroy()` | 서블릿 종료 시 (1회 실행)      | 자원 정리, 연결 해제 |
