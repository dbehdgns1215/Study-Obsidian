# 📘 [프로젝트명] 백엔드 개발 환경 가이드

이 문서는 프로젝트의 **로컬 개발 환경 구축** 및 **DB 형상 관리 규칙**을 설명합니다.

모든 팀원은 개발 시작 전 반드시 아래 내용을 숙지하고 환경을 세팅해 주세요.

---

## ✅ 1. 사전 준비 (Prerequisites)

다음 도구들이 PC에 설치되어 있어야 합니다.

- **Java 21 (JDK 21)**
    
- **IntelliJ IDEA** (권장)
    
- **Docker Desktop** (또는 Docker Engine)
    
    - _DB를 로컬에 직접 설치하지 않고 Docker 컨테이너로 띄웁니다._
        

---

## 🚀 2. 프로젝트 실행 방법 (Getting Started)

### Step 1. 프로젝트 클론

Bash

```
git clone https://gitlab.com/your-repo/project-name.git
cd project-name
```

### Step 2. 로컬 DB 실행 (Docker)

프로젝트 루트 경로에서 아래 명령어를 입력하여 로컬 개발용 DB(PostgreSQL)를 실행합니다.

Bash

```
# DB 컨테이너 실행 (백그라운드 모드)
docker-compose up -d

# 실행 확인 (STATUS가 Up인지 확인)
docker ps
```

> **참고:** 이 명령어를 실행하면 `localhost:5432` 포트로 PostgreSQL이 실행됩니다.

### Step 3. 애플리케이션 실행

1. IntelliJ에서 프로젝트를 엽니다.
    
2. `src/main/java/.../Application.java` 파일을 엽니다.
    
3. **Run (▶)** 버튼을 눌러 스프링 부트를 실행합니다.
    

> **💡 최초 실행 시 주의사항** > 스프링 부트가 시작되면서 **Flyway**가 자동으로 작동하여, DB에 필요한 테이블(`schema`)을 모두 생성합니다. 별도의 `CREATE TABLE` 쿼리를 날릴 필요가 없습니다.

---

## 🗄️ 3. DB 변경 및 관리 규칙 (Flyway)

우리는 **Flyway**를 사용하여 DB 스키마를 코드로 관리합니다.

**절대로 로컬 DB에서 수동으로 `ALTER TABLE` 등을 수행하지 마세요.**

### 규칙

1. **Entity 수정 시:** Java 코드를 수정한 후, 반드시 대응되는 **SQL 마이그레이션 파일**을 생성해야 합니다.
    
2. **파일 위치:** `src/main/resources/db/migration/`
    
3. **파일명 규칙:** `V{숫자}__{설명}.sql` (언더바 2개 주의!)
    

### 예시

새로운 기능을 위해 User 테이블에 `age` 컬럼을 추가해야 한다면?

1. `src/main/resources/db/migration/` 폴더에 파일 생성
    
2. 파일명: **`V2__add_age_to_user.sql`**
    
3. 내용 작성:
    
    SQL
    
    ```
    ALTER TABLE users ADD COLUMN age INTEGER;
    ```
    
4. 서버를 재시작하면 Flyway가 자동으로 감지하여 반영합니다.

## ⚠️ 4. 인프라 파일 건드리지 마시오

프로젝트 루트에 있는 다음 파일들은 **서버 배포 및 운영**을 위한 파일입니다.

**로컬 개발 시에는 수정할 필요가 없으니 주의해주세요.**

- `Dockerfile` (젠킨스 빌드용)
    
- `docker-compose-prod.yml` (EC2 운영 서버용)
    

> 로컬 개발 설정을 바꾸고 싶다면 `docker-compose.yml` (개발용) 만 수정하세요.

---

## 🛠️ 5. 자주 쓰는 명령어

**DB 컨테이너 중지 및 삭제 (퇴근 시)**

Bash

```
docker-compose down
```

**DB 데이터까지 싹 날리고 초기화하고 싶을 때**

Bash

```
# 볼륨(-v)까지 삭제
docker-compose down -v 
docker-compose up -d
```

_(주의: 로컬 DB의 모든 데이터가 삭제되고, 재시작 시 Flyway가 테이블을 다시 처음부터 생성합니다.)_
