# 사과 먹기 게임
- Java: 3초, 256MB

사용자는 사과 먹기 게임을 하려고 한다. 사과 먹기 게임이란, 게임 화면 속 나타나는 사과를 순서대로 먹으면 되는 게임이다. 제일 처음 입력으로 테스트 케이스의 수 `T`가 주어지고 이후 게임 판의 한 변의 크기인 `N`이 입력된다. 전체 게임 판은 `N * N` 배열로 이루어져 있다.

사용자는 항상 좌측 상단에서 게임을 진행하며, 게임을 시작하면 첫 번째 사과가 나타나고 첫 번째 사과를 먹었다면 이후에는 두 번째 사과가 나타난다. 두 번째 사과를 먹었다면 세 번째 사과가 나타나며, 이렇게 차례대로 사과를 먹으면 된다. 사과는 게임 판에서 `1`부터 `10`까지의 숫자로 주어진다.

또한 `<그림 2>` 와 같이 `N`번째 사과의 다음인 `N + 1`번째 사과는 같은 `행`, 같은 `열`에 생기지 않는다.

마지막으로 사용자의 게임기는 고장이 났기 때문에 `오른쪽`으로 밖에 회전하지 못한다. 따라서 차례대로 사과를 먹어 나갈 때, `최소 회전 횟수`를 구하라.

![[KakaoTalk_20250903_005703424_02.jpg]]
								`<그림 3>`
`<그림 3>` 의 경우, 총 회전 횟수는 `7`번이다.


- 사과 개수 (`2 <= 사과 <= 10)` // 입력으로 나오는 게 아니고 
- `N`은 언제나 홀수, `5 <= N <= ?` // 기억이 안남


## 입력
```input
5
5
00000
00030
01000
00200
00000
5
00000
03000
00200
00410
00000

후략...
```

## 출력
```output
7
9
후략...
```

- 어떻게 접근했나?
	- `Apple` 클래스 정의
	- `int x, int y`
	- `public int findApple(int curX, curY)`
		- 현재 위치 `(curX, curY)`에서 먹어야 하는 사과로의 회전 횟수를 구하는 함수
		- 실제 이동 처리를 하는 것이 아님.
		- 내 위치 기준으로 사분면을 나눠서 처리
		- 또한, 현재 내가 향하고 있는 방향 `dir`을 `전역 변수`로 가져감.
			- `dir` : `1, 2, 3, 4` `(우, 하, 좌, 상)`
		- 예를 들어, 좌측 상단에서  `dir == 1` 인 상태로 시작하면 첫 번째 사과의 경우 `3사분면`에 위치하게 됨. 3사분면으로 이동하는 가장 빠른 루트는 문제 예시처럼 직진하다가 같은 `열`에서 `우회전`하면 됨.
			- 따라서 `dir = 2` 가 되며 회전 횟수인 `1`을 반환해줌
				- `main` 로직 내에서 해당 회전 횟수들을 계속 `cnt`에 더해줬음
		- 이러한 큰 로직을 잡고, 각 `dir`마다 `사분면`에 따른 `회전 횟수` 및 `dir`을 정의서 사과 개수만큼 `for`문을 돌렸음.
	- `Apple` 배열로 사과를 저장
		- 사과는 결국 `1`부터 최대 `10`까지 순서대로 먹어야 하고 현재 사과를 먹기 전까지 다음 사과가 나타나지 않으니까 일관되게 이동할 수 있을 거라고 판단함. (장애물이 존재하지 않음)

![[Pasted image 20250903011506.png]]
- `dir = 1` 일 때 `사분면`에 따른 `회전 횟수`
- 처음에는 시계 방향으로 1씩 증가하는 줄 알았는데, 문제에서 주어진 가장자리를 잘 이용하면 `1, 2, 3, 3`의 값이 나오게 됨.
- 추가로 전역 변수로 잡아놓은 `dir`은 매 호출마다 업데이트 해줘서 다음 사과를 찾으러 갈 때 사용할 수 있게 함.
	- 사진 속에서 1사분면에 있는 사과를 먹으러 간다면
	- `cnt += 3`, `dir = 4`
- 누군가의 증언으로는 BFS로 푼 사람도 있다고 들었음
