# 풍선 사격 게임
- Java: 3초, 256mb

다음과 같이 N개의 풍선이 있나?

![[Pasted image 20250903012832.png]]

특정 풍선을 터트렸을 때, 3가지 경우의 수가 있다.

- 좌, 우 모두 인접한 풍선이 있을 경우 해당 풍선에 적힌 숫자의 `곱`을 점수로 획득한다.
- 좌, 우에 인접한 풍선이 하나만 있을 경우, 해당 풍선에 적힌 `숫자`를 점수로 획득한다.
- 좌, 우에 풍선이 없을 경우, 터진 풍선에 적힌 `숫자`를 점수로 획득한다.

풍선이 터졌을 때, 남은 풍선들은 자연스럽게 간격이 조정된다.

이때 획득할 수 있는 최대 점수를 구하여라.

`<예시>`
![[Pasted image 20250903013053.png]]
- 3번째 풍선을 터트렸을 때, 2번 풍선과 4번 풍선에 적힌 숫자들의 `곱`: `8`을 점수로 획득


![[Pasted image 20250903013134.png]]
- 간격이 조정되고, 2번째 풍선을 터트렸을 때, 1번 풍선과 4번 풍선에 적힌 숫자들의 `곱`: `4`를 점수로 획득한다.

![[Pasted image 20250903013211.png]]
- 이 상황의 경우, 1번 풍선을 터트린다면 우측에만 풍선이 있기 때문에, 우측에 위치한 째 풍선에 적힌 숫자 `4`를 점수로 획득한다.

![[Pasted image 20250903013251.png]]
- 풍선이 하나만 남은 경우, 이 풍선을 터트리면 풍선에 적힌 숫자 `4`를 점수로 획득한다.

- 도합 `17점`
	- 근데 이게 맞는 지 모르겠음.
	- 사실 2번을 30분동안 깔짝하다가 끝나버림.
- 실제 최대값은 `20`점 `2->1->3->4`
- 부분집합 백트래킹으로 접근 했었는데, 다른 사람들은 순열로 접근한 것 같음
- 자세한 입출력 예시나 세세한 디테일은 기억이 나지 않음..
