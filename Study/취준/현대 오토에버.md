### 1. 선형 자료구조 (Array & List)

- **Array (배열)**
    
    - 특징: 크기가 고정되어 있으며, 인덱스를 통한 조회 속도가 매우 빠름(O(1)).
        
    - 선언: `int[] arr = new int[n];`
        
    - 주요 메서드: `arr.length`, `Arrays.sort(arr)`, `Arrays.copyOf(arr, length)`
        
- **ArrayList**
    
    - 특징: 가변 크기 배열. 코딩 테스트에서 가장 범용적으로 사용됨. 인덱스 조회는 빠르나 중간 삽입/삭제는 느림.
        
    - 선언: `List<Integer> list = new ArrayList<>();`
        
    - 주요 메서드: `add(e)`, `get(index)`, `size()`, `remove(index)`, `contains(e)`, `Collections.sort(list)`
        
- **LinkedList**
    
    - 특징: 노드 간 연결 구조. 양 끝의 삽입과 삭제가 빈번할 때 유리함(O(1)).
        
    - 선언: `List<Integer> list = new LinkedList<>();`
        
    - 주요 메서드: `addFirst(e)`, `addLast(e)`, `removeFirst()`, `removeLast()`
        

### 2. 고유값 및 정렬 자료구조 (Set)

- **HashSet**
    
    - 특징: 중복을 허용하지 않으며 순서가 보장되지 않음. 데이터 존재 여부 확인이 매우 빠름(O(1)).
        
    - 선언: `Set<Integer> set = new HashSet<>();`
        
    - 주요 메서드: `add(e)`, `contains(e)`, `remove(e)`, `size()`
        
- **TreeSet**
    
    - 특징: 중복을 허용하지 않으며, 데이터가 자동으로 오름차순 정렬됨. 범위 검색에 유리함.
        
    - 선언: `TreeSet<Integer> set = new TreeSet<>();`
        
    - 주요 메서드: `first()`, `last()`, `higher(e)`, `lower(e)`, `subSet(from, to)`
        

### 3. 키-값 쌍 자료구조 (Map)

- **HashMap**
    
    - 특징: Key-Value 쌍으로 저장. Key는 중복 불가. 검색, 삽입 성능이 매우 우수함(O(1)).
        
    - 선언: `Map<String, Integer> map = new HashMap<>();`
        
    - 주요 메서드: `put(k, v)`, `get(k)`, `getOrDefault(k, default)`, `containsKey(k)`, `keySet()`
        
- **TreeMap**
    
    - 특징: Key를 기준으로 자동 정렬되는 Map. 정렬된 상태로 Map을 순회해야 할 때 사용.
        
    - 선언: `TreeMap<String, Integer> map = new TreeMap<>();`
        
    - 주요 메서드: `firstKey()`, `lastKey()`, `higherKey(k)`, `lowerKey(k)`
        

### 4. 스택, 큐, 덱 (Stack, Queue, Deque)

- **Stack**
    
    - 특징: 후입선출(LIFO). 최근에는 Deque 인터페이스를 더 권장하지만 코테에서는 여전히 자주 쓰임.
        
    - 선언: `Stack<Integer> stack = new Stack<>();`
        
    - 주요 메서드: `push(e)`, `pop()`, `peek()`, `isEmpty()`
        
- **Queue**
    
    - 특징: 선입선출(FIFO). BFS 알고리즘 구현 시 필수적임.
        
    - 선언: `Queue<Integer> q = new LinkedList<>();`
        
    - 주요 메서드: `offer(e)`, `poll()`, `peek()`, `size()`
        
- **Deque (ArrayDeque)**
    
    - 특징: 양쪽 끝에서 삽입/삭제 가능. Stack과 Queue의 기능을 모두 포함하며 성능이 우수함.
        
    - 선언: `Deque<Integer> dq = new ArrayDeque<>();`
        
    - 주요 메서드: `addFirst(e)`, `addLast(e)`, `pollFirst()`, `pollLast()`
        
- **PriorityQueue**
    
    - 특징: 내부적으로 힙(Heap) 구조. 가장 작거나 큰 값을 우선적으로 추출함(O(log N)).
        
    - 선언: `PriorityQueue<Integer> pq = new PriorityQueue<>();`
        
    - 주요 메서드: `offer(e)`, `poll()`, `peek()`
        

### 5. 문자열 처리 (String)

- **StringBuilder**
    
    - 특징: 가변적인 문자열 조작 가능. `+` 연산보다 성능이 압도적으로 좋아 코테 필수 도구임.
        
    - 선언: `StringBuilder sb = new StringBuilder();`
        
    - 주요 메서드: `append(s)`, `insert(offset, s)`, `delete(start, end)`, `reverse()`, `toString()`
